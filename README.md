# HopeFinder

HopeFinder is a comprehensive missing persons detection system using AI-powered face recognition from CCTV footage. Features include real-time detection, admin dashboard, police integration, notifications, and more.

## Key Components
- **AI Detection**: Multi-camera face recognition using DeepFace
- **Admin Panel**: Manage missing persons, found reports, police assignments
- **Realtime Dashboard**: Live detections and matches
- **Database**: MySQL backend for reports and matches

## Setup
1. Clone the repo
2. Setup database using schema files in `Database/`
3. Run AI server: `ai_multi_test/RUN_ALL.bat`
4. Access admin panel and dashboards

See individual READMEs for detailed instructions.
